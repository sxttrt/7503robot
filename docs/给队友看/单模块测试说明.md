# 单模块测试说明

做完一个模块就可以先测，不需要等整车完成。现有 ROS 接口可直接观察或调用；本页提供手动测试入口，暂未提供一键验收工具。

## 上板测试与联系

模块完成后需要在实机上测试。需要取用板子、部署程序、烧录固件或现场联调时，在微信群里联系我（**刘承韬**）；开发或接口对接有问题，也可以在群里交流。

建议使用 **VS Code Remote-SSH** 连接树莓派，直接编辑代码、编译和运行测试。树莓派程序部署运行，ESP32 固件需要烧录。

## 单模块测试如何开始

1. 按 README 构建本工程，再构建你自己的 ROS 包。
2. 终端一只启动待测模块及它需要的驱动，不启动主状态机，不启动整套模拟。
3. 终端二设置相同通信域、加载两个工作区后，执行下面的观察／调用命令。

两个终端都要设置：

```bash
source /opt/ros/jazzy/setup.bash
source ~/7503robot_ws/install/setup.bash
# 自己的模块在另一工作区时，再加载该工作区的 install/setup.bash。
export ROS_DOMAIN_ID=42
# 本说明用于同一台电脑测试；跨电脑联调需统一发现设置。
export ROS_AUTOMATIC_DISCOVERY_RANGE=LOCALHOST
export ROS_STATIC_PEERS=''
```

本页使用默认实机名称 `/team2/robot/...`。自己的节点需使用命名空间 `team2/robot`，或通过重映射提供对应接口。相对名称和类型以《模块接口说明》及 `interfaces.yaml` 为准。

## 按任务选择测试

单模块测试不启动主状态机，因此无需先准备整机健康发布者。测试命令只调用当前模块。

### QR：看识别输出

```bash
ros2 topic echo /team2/robot/qr/detections
```

展示正确标签、其他标签和无标签，核对完整 raw 与图像时间。具体格式见 [接口说明](模块接口说明.md)。

### 导航：只发点位名称

```bash
# 去 A；导航模块自行决定位置、朝向和路线。
ros2 action send_goal /team2/robot/navigate_to_point mission_interfaces/action/NavigateToPoint \
  '{target_id: A}' --feedback

# 去放置区；按实际测试需要分别执行。
ros2 action send_goal /team2/robot/navigate_to_point mission_interfaces/action/NavigateToPoint \
  '{target_id: DROP_OFF}' --feedback
```

去 B/C/D 就替换 target_id。队友自己的导航模块需要准备相应点位。到达并停止后返回 `success=true` 和 Action 成功；失败返回 false 和原因，支持标准取消。主程序不要求地图坐标、朝向或二次到点反馈。

### 对准：发 ENTER 或 EXIT

```bash
ros2 action send_goal /team2/robot/docking/execute mission_interfaces/action/Dock \
  "{request_id: test_A_enter_001, operation: ENTER, rack_id: A, expected_qr: 'RACKA_实际后缀', max_duration_sec: 15.0}" --feedback
```

换成本队真实 QR。ENTER 做完进入并可托举后返回成功；EXIT 做完退出后返回成功。退出测试将 operation 改为 EXIT。主程序不再额外要求 ready_to_lift／exited 标志。

### 升降：直接升／降

```bash
# 分别执行，等上一步结束；不需要编号或令牌。
ros2 service call /team2/robot/lift/set_up std_srvs/srv/SetBool '{data: true}'
ros2 service call /team2/robot/lift/set_up std_srvs/srv/SetBool '{data: false}'
```

模块完成后返回 `success`、`message`。到位如何判断由模块自行实现，主程序不要求额外传感器来源字段。不要与主状态机同时控制同一机构。

### 停止：调用停止接口

```bash
ros2 service call /team2/robot/safety/stop std_srvs/srv/Trigger '{}'
```

模块执行停止后返回成功或失败及原因，主程序直接使用返回结果。单模块实测时观察机构确实停止，交接时提供测试结果；程序不再要求另一份确认消息。

### 在线反馈：整机联调时准备

```bash
ros2 topic echo /team2/robot/robot/status
```

集成端定期发布 `{"ready": true, "fault": ""}` 即可，不需要五模块明细、时间戳、升降来源或令牌。单模块调用无需这条反馈。
